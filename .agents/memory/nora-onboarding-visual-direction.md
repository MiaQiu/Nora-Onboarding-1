---
name: Nora onboarding visual direction
description: User-directed visual constraints for future Nora onboarding edits.
---

For the Nora onboarding, use a light, narrow, focused flow with restrained purple branding and clear visual emphasis on the important phrases in educational screens. The user supplied Leaply's child-development funnel as a style reference, not as a source for copied imagery or text.

**Why:** The user explicitly disliked the prior saturated full-purple page and asked for a style closer to the reference while retaining Nora's purple identity. They also asked for insight screens to highlight key messages.

**How to apply:** Keep future onboarding design changes consistent with this calmer visual direction unless the user asks for a new one. Preserve the supplied Nora copy when highlighting it.

Do not represent “Doesn't listen” with a crossed-out ear or hearing-loss symbol.

**Why:** The user rejected that icon because it looked like deafness rather than a parenting challenge.

**How to apply:** Use a communication-related visual for this choice without implying hearing impairment.

Use warm parent-and-child illustrations for the parent-learning, play, and screen-time transition insight pages, rather than abstract figures or device-and-clock diagrams.

**Why:** The user disliked the original learning/play visuals and explicitly selected warm parent-and-child illustrations, then also rejected the abstract transition diagram.

**How to apply:** Keep future replacements for these pages human and approachable while preserving the restrained purple branding.
